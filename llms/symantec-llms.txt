- [About the ZTNA APIs](/resources/configs/_markdown/ztna_about.md): Overview of Zero Trust Network Access APIs
- [Authenticate to the API](/resources/configs/_markdown/ztna_auth.md): Authentication and authorization for ZTNA APIs
- [What's New in ZTNA APIs v2](/resources/configs/_markdown/ztna_whats_new.md): What's New in ZTNA APIs v2
- [Sites](/resources/configs/_markdown/ztna_sites.md): Create and manage ZTNA sites, including the new Orchestrator authentication mode.
- [Site Registration Keys](/resources/configs/_markdown/ztna_site_reg_keys.md): Manage long-lived tokens for automated connector registration in Orchestrator-mode sites.
- [Connectors](/resources/configs/_markdown/ztna_connectors.md): Create and manage ZTNA connectors, including deployment commands and environment variables.
- [Applications](/resources/configs/_markdown/ztna_apps.md): Create and manage ZTNA applications, bind them to sites, and monitor application health.
- [Access and Activity Policies](/resources/configs/_markdown/ztna_policies.md): Create and manage ZTNA access and activity policies, bind policies to applications and entities.
- [Shared Objects](/resources/configs/_markdown/ztna_shared_objects.md): Create and manage shared objects that can be reused across ZTNA policies.
- [Collections](/resources/configs/_markdown/ztna_collections.md): Create and manage collections of sites, and manage role bindings for tenant, collection, and site scopes.
- [DNS Resiliency](/resources/configs/_markdown/ztna_dns.md): Create and manage DNS groups and servers for ZTNA DNS resiliency and failover.
- [Identity Providers](/resources/configs/_markdown/ztna_idps.md): Retrieve the list of configured identity providers for your ZTNA tenant.
- [Users](/resources/configs/_markdown/ztna_users.md): Create and manage ZTNA users, including local users and users from external identity providers.
- [Groups](/resources/configs/_markdown/ztna_groups.md): Create and manage ZTNA groups, assign users to groups, and search groups by identity provider.
- [SSH Clients](/resources/configs/_markdown/ztna_ssh.md): Retrieve SSH client information for users in your ZTNA tenant.
- [SCIM](/resources/configs/_markdown/ztna_scim.md): Manage ZTNA users and groups using the SCIM 2.0 protocol for automated provisioning.
- [Cloud Integrations](/resources/configs/_markdown/ztna_cloud_integ.md): Create and manage cloud integration configurations for auto-discovery of cloud resources.
- [Audit Logs](/resources/configs/_markdown/ztna_audit.md): Search and retrieve audit log events for your ZTNA tenant.
- [Forensic Logs](/resources/configs/_markdown/ztna_forensic.md): Search and retrieve forensics log events for your ZTNA tenant.
- [Observability](/resources/configs/_markdown/ztna_observability.md): Automated connector management and system health monitoring
